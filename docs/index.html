一、今日精析｜广东按病种付费经办规程：DRG/DIP 从“扩面”走向“精细化管理”（医疗保障学）

1. 案例材料（可直接作材料分析题题干）

2026年3月12日，广东省医疗保障局印发《广东省按病种付费医疗保障经办管理规程》，自2026年5月1日起施行，有效期5年。规程把 DRG（按疾病诊断相关分组付费）和 DIP（按病种分值付费）统一纳入“按病种付费”，覆盖协议管理、数据采集、预算管理、核心要素、特殊病例单议、结算清算、审核核查、配套机制等环节。

在预算端，年度按病种付费可分配资金总额增长率不得高于10%，可预留不超过10%的风险调节金用于合理超支分担；在结算端，月度结算可预留不超过5%的质量保证金，并要求压缩结算周期、推进即时结算；在例外端，住院时间长、费用高、使用新药新技术的复杂病例可申报“特殊病例单议”，例数原则上不超过 DRG 结算人次的5%或 DIP 结算人次的5‰；在监管端，要求对高套病种、分解住院、低标入院、推诿病人、转嫁住院费用等疑点开展核查，并将考核评价与年度清算挂钩。

这套规则承接国家医保局2025年印发的《医疗保障按病种付费管理暂行办法》和《按病种付费医疗保障经办管理规程（2025版）》，标志着按病种付费从“扩面”进入“精细化管理”阶段。

4. 命题角度

  • 名词解释：按病种付费（DRG/DIP）
  • 简答：简述按病种付费“预算—分组—结算—清算—监管”闭环的基本内容。
  • 论述：结合广东规程，论述 DRG/DIP 支付方式改革对医院行为、患者负担和医保基金的影响，并提出配套政策。
  • 材料分析：材料中的“总额预算增长率不高于10%”“特殊病例单议”“质量保证金”分别解决什么问题？这对医保精细化管理有何启示？

5. 答题框架（背这一页）

（1）内涵：从“为项目买单”到“为病种/健康结果买单” 按病种付费把医保基金从“按服务数量付费”转为“按病种打包付费”，医保部门从“被动报销”转向“战略购买”，医院从“多做项目多收入”转向“控成本、提效率、保质量”。

（2）机制：一个闭环 预算（区域总额、增长率上限、风险调节金）→ 分组（DRG 细分组 / DIP 病种目录）→ 分值或点值 → 月度结算（质量保证金、即时结算）→ 年度清算（结余留用、超支分担、二次分配）→ 考核监管（智能审核、特殊病例单议、协议管理）。

（3）影响：三方两面的“双刃剑”

  • 医院：倒逼成本核算、病案质量、临床路径、学科结构调整；风险是高套病种、分解住院、低标入院、推诿重症、抑制新技术。
  • 患者：控费可减轻负担，但若监管不到位，可能出现服务不足、推诿、自费转嫁。
  • 医保：提高基金使用效率、增强可持续性，但需防止“控费”压倒“提质”。

（4）配套：用“例外机制+质量考核”校准激励 特殊病例单议守住重症和新技术的可及性；质量保证金和考核评价防止“为控费而降质”；智能审核和协议管理守住基金安全；协商谈判和数据公开降低医院的不确定性；紧密型医共体总额付费则把“控费”升级为“健康管理”。

（5）收束 支付方式改革不是单纯“控费”，而是医保购买机制的重构；成败不只在分组技术，更在利益分配、质量考核和多部门协同。

一句话收束：总额预算管住“总盘子”，结余留用形成“内生动力”，特殊病例单议守住“例外公平”，智能监管守住“基金安全”。

6. 金句与术语

  1. “从按项目付费转向按病种付费，本质是把医保基金从‘为服务数量买单’转向‘为合理诊疗和健康结果买单’。”
  2. “DRG/DIP 不是万能钥匙，单病种付费可能带来高套、分解、推诿等逆向选择，必须用质量考核和例外机制校准。”
  3. “支付方式是医保、医疗、医药协同发展的‘总开关’。”
  4. “改革的难点不在技术分组，而在利益分配与行为激励。”
  5. “控费是手段，提质是目的，患者获益是底线。”

速览 1｜胖东来37.93亿元资产转员工股本：一场“利润共享”的管理实验（管理学）

  • 事实：2026年3月8日，胖东来创始人于东来公布资产分配方案：集团10194名员工，资产总额37.93亿元；管理团队718人对应39.9%，技术团队563人对应12.3%，一线员工8913人对应47.7%，其中8633名普通员工按人均20万元分配。未来资产作为公司股本，每年利润的50%给团队发奖金、50%归股东。2月23—24日的内部调研回收9686份有效问卷（回收率94.83%），82.38%的员工拒绝“降薪增假”，78.83%对现有每年40天休假“非常满意”。此前，于东来于2月11日宣布春节后退休；2月12日又表示胖东来“永不上市”、做“学校式企业”。
  • 核心考点：人本管理、需要层次理论、双因素理论、公平理论、利益相关者理论、组织文化、员工参与和民主管理。
  • 命题角度：结合胖东来，分析“高薪酬+高休假+高要求”模式为何能同时实现员工满意与组织绩效；其可复制性边界是什么？
  • 一句话结论：高投入换高认同，高认同换高服务，高服务换高绩效；可复制的是利润共享、民主参与、尊严保护机制，不可复制的是创始人价值观、区域市场与规模克制。
  • 来源：证券时报（界面新闻）2026-03-09

速览 2｜北大医院大兴院区“班子与科室面对面”：多院区协同中的组织沟通（组织行为学）

  • 事实：2026年7月21日，北京大学第一医院大兴院区召开“党建引领高质量发展”专题座谈会，院区班子与临床、医技、职能科室负责人面对面，把人才梯队、暑期高峰人力调配、双向转诊衔接、资源灵活配置、信息化支撑等问题摆上桌面，职能部门现场认领、承诺限时办结。大兴院区2026年上半年门诊人次同比增长24.4%，手术人次增长53.49%，四级手术人次增长46.26%；其“48小时例会制度”在开办期开了87次例会，3个月完成消防和竣工验收、2个月办好医疗备案，2023年12月18日正式启用。
  • 核心考点：组织沟通（上行/下行/平行）、群体决策、问题导向管理、变革型领导、组织支持、跨部门协同、组织学习。
  • 命题角度：结合案例，分析“面对面座谈会+问题清单+限时办结”在医院多院区管理中的作用与局限。
  • 一句话结论：高频沟通降低信息不对称，现场认领形成责任闭环，党建引领提供合法性；但需制度化、数据化、授权化，避免“运动式治理”。
  • 来源：北京大学第一医院官网 2026-07-24

速览 3｜广东县域医共体“新三年”：从“建起来”到“紧密起来”（卫生事业管理学）

  • 事实：2026年10月8日，广东省政府办公厅印发《广东省紧密型县域医疗卫生共同体高质量发展行动方案（2026—2028年）》（粤办函〔2026〕297号）。方案提出：2026年推动90%以上县域医共体达到医保支付改革申请条件；到2027年底，100%的县域医共体实现统一法定代表人、100%实现覆盖全部基层分院的“分布式检查、集中式诊断”；到2028年底，力争85%以上的县域基层诊疗量占比达65%以上，60%的县域医共体建成信息平台，基层分院药品配备品种数比2025年提高20%，县域内中医类诊疗量占比提高到35%。同时要求每个基层分院至少有1名上级医院中级及以上职称人员派驻帮扶、连续半年以上，医保结余留用向基层和健康管理倾斜，推行“县域医共体一张床”。
  • 核心考点：分级诊疗、紧密型县域医共体、卫生资源配置、卫生规划、整合型医疗服务体系、医保支付协同、强基层。
  • 命题角度：结合广东行动方案，论述紧密型县域医共体“紧密”的内涵、建设难点与对策。
  • 一句话结论：紧密不靠“挂牌”，靠统一法人、统一财务、统一人事、统一药械、统一信息、统一绩效，再加医保总额付费、人才下沉和健康结果考核。
  • 来源：广东省人民政府 2026-10-27

《医疗保障法（草案）》三审：医保治理从“政策推动”走向“法治保障”

专题
入库：2026-11-20
主科目：医疗保障学　辅科目：公共政策导论
为什么现在做：2026-08-25 草案三审；长护险拟入法、异地就医结算细化、基金监管充实；2026-04-30—05-29 公开征求意见收到 343 人次 1845 条意见。
考试价值：这是 828 里“医保 + 法治 + 政策过程”的交叉题，可出名词解释、简答、论述、材料分析四种题型。

一、案例材料（可作材料分析题题干）

2026年8月25日，十四届全国人大常委会第二十四次会议审议《中华人民共和国医疗保障法（草案）》三审稿。草案二审稿已于2026年4月提请十四届全国人大常委会第二十二次会议审议。2026年4月30日至5月29日公开征求意见期间，中国人大网收到343人次提出的1845条意见，代表工作信息化平台收到14位全国人大代表提出的39条意见，另收到来信10封。

三审稿拟作六方面修改：一是立法目的进一步体现健康优先发展战略；二是完善医疗保障体系有关规定；三是充实医疗保障基金管理有关规定；四是细化异地就医医药费用结算要求；五是增加长期护理保险相关规定；六是完善有关法律责任规定。

在基金管理方面，草案明确：国务院医疗保障行政部门在组织制定基本医疗保险基金支付范围、组织开展循证医学和经济性评价时，除征求有关部门意见外，还应当采取适当方式听取医疗机构、药品经营单位、相关企业、专家和参保人员的意见；建立和完善药品、医用耗材集中采购制度；实行多元复合式医疗保险支付方式；优化异地就医直接结算服务。

目前草案仍处于审议阶段，尚未颁布实施。

二、事实与来源

五、答题框架（背这一页）

（1）为什么立法：从“政策推动”到“法治保障” 医保改革已进入深水区，靠文件推动容易出现政策碎片化、地方执行差异、部门协调困难。把医保体系、基金、待遇、支付、监管等基本制度上升为法律，可以稳定预期、规范权力、保障参保人权利，为“三医协同”提供法治基础。

（2）立法过程：一次典型的政策合法化 起草 → 公开征求意见（343人次、1845条意见）→ 二审 → 三审 → 表决通过 → 公布施行。公开征求意见把医疗机构、医药企业、专家、参保人的多元利益纳入决策，提高立法的科学性与民主性；人大审议则完成合法性确认。

（3）三审亮点：六个“更”

  • 立法目的更鲜明：体现健康优先发展战略；
  • 体系更完整：完善医疗保障体系有关规定；
  • 基金更安全：充实基金管理规定，支付范围、循证医学和经济性评价要听取多方意见；
  • 结算更便捷：细化异地就医医药费用结算；
  • 制度更定型：增加长期护理保险；
  • 责任更严格：完善法律责任规定。

（4）难点：立法之后怎么落地 部门协同（医保、卫健、药监、财政）、央地事权与支出责任、待遇公平与基金可持续、长护险筹资与失能评估、法律与现行政策的衔接、监管能力与执法队伍。

（5）意义：医保治理现代化 对参保人：权利有法律保障；对医疗机构：规则更稳定、预期更明确；对医保部门：从行政推动转向依法治理；对医药企业：集采、支付、价格规则法治化；对国家：多层次医疗保障体系和健康中国战略的法治支撑。

一句话收束：医保法不是把现有政策简单“抄”进法律，而是把医保治理的基本关系、基本规则和基本责任固定下来，让改革“于法有据”。
