一、今日精析｜长期护理保险从“试点破冰”到“全国建制”：一场关于“照护”的制度长征（跨学科：医疗保障学＋卫生事业管理学＋公共政策导论）

1. 案例材料（可直接作材料分析题题干）

2026年3月25日，中共中央办公厅、国务院办公厅印发《关于加快建立长期护理保险制度的意见》，提出用3年左右时间，基本建立适应我国基本国情的长期护理保险制度。意见明确：费率统一控制在0.3%左右，单位职工由用人单位和个人同比例分担；未就业城乡居民从0.15%左右起步，用5年左右逐步过渡到0.3%左右；职工参保基金支付比例为70%左右，居民为50%左右；失能状态长期持续（一般为6个月以上）、经评估认定后可享受待遇，起步阶段保障重度失能人员；基金主要用于支付护理服务费用，原则上不直接向失能人员发放现金。

2026年9月4日，国家医保局在国新办“开局起步‘十五五’”系列主题新闻发布会上披露：22个省份已印发省级实施方案，建制统筹地区达到121个，预计2026年底拓展至247个；参保人数超过3.2亿，基金累计支出1142亿元，惠及超过460万失能人员；全国定点长护服务机构1.3万家，是试点初期的10倍，护理服务人员约40万人，培养长期照护师超过7万名，拉动社会资本投入近700亿元。按照部署，到2028年底，长护险制度要在全国基本实现全覆盖。

在地方，宁波自2017年起成为全国首批试点城市，2023年全面启动深化试点，形成“1+10”政策框架，建立资金筹集、需求评估、待遇支付、服务供给、经办管理五大体系；截至2026年6月底，全市参保846万人，累计惠及5.3万名重度失能人员。与此同时，护理服务供给不足、失能评估标准不一、基金监管难度大、城乡待遇差距等问题，也在试点中逐渐显现。

4. 命题角度

  • 名词解释：长期护理保险；失能等级评估。
  • 简答：简述长期护理保险制度“筹资—评估—待遇—服务—监管”的基本框架。
  • 论述：结合长护险从试点到全国建制，论述其条件、难点与对策。
  • 材料分析：结合材料，分析“0.3%费率”“职工70%、居民50%”“2028年底全覆盖”的政策意图，并指出可能的风险。

5. 答题框架（背这一页）

（1）诊断/背景：为什么需要“第六险”

人口老龄化加深、失能风险上升、家庭小型化与女性劳动参与提高，使“一人失能、全家失衡”成为普遍困境。医疗保险保“治病”，养老保险保“收入”，但失能后的长期生活照料和护理，既不是医保险种能全包，也不是家庭能独自承担；长护险填补的正是“失能后的照护”这一制度空白。

（2）机制：一个“五体系”闭环

筹资（0.3%费率、单位个人分担、居民0.15%起步、财政补助、医保结余划转）→ 评估（全国统一失能标准、独立评估机构、结果互认）→ 待遇（70%/50%、无起付线、年度限额、居家社区倾斜、不发现金）→ 服务（定点机构、居家/社区/机构、医养结合、照护师）→ 经办监管（协议管理、服务质量评价、智能监控、基金监管）。五个环节环环相扣：筹资决定“能不能保”，评估决定“保给谁”，待遇决定“保多少”，服务决定“保得好不好”，监管决定“保得久不久”。

（3）影响：三重效应

对家庭：减轻经济负担和照护时间压力，把“私人的照护”变成“社会的制度”。对产业：带动护理服务、辅具、智能设备、银发经济，创造就业（40万护理人员、7万照护师、近700亿元社会资本）。对治理：从“政策推动”走向“制度定型”，为医保、卫健、民政、财政多部门协同提供新载体。但也要看到：待遇刚性上升、基金支出压力、护理服务供给不足、城乡和群体待遇差距，可能带来新的不公平。

（4）难点：四个“不平衡”

一是筹资与待遇不平衡：0.3%的费率在老龄化加深、待遇刚性的背景下是否可持续，居民0.15%起步后能否顺利过渡，职工医保结余划转的边界在哪里。二是评估与服务不平衡：标准统一了，但评估机构能力、评估质量、结果互认仍有差距，护理服务供给（尤其农村和居家社区）跟不上。三是监管与创新不平衡：服务无形、难以计量，虚假服务、挂床、骗保风险高，智能监管和跨部门协同不足。四是城乡与群体不平衡：职工70%、居民50%，居民缴费能力弱，待遇差距可能扩大。

（5）对策：从“建起来”到“稳下来”

筹资端：建立基准费率+动态调整+精算平衡机制，明确财政补助责任，职工医保结余划转要“充分测算、保障医保待遇”。评估端：统一标准、评估机构准入和质控、复评抽查、结果互认、数字化。服务端：以居家社区为重点，推动基层医疗机构、养老机构、护理院协同，加快照护师培养、职称和薪酬体系建设。监管端：智能监控+飞行检查+协议管理+信用管理+信息披露。协同端：医保、卫健、民政、财政、人社、残联数据共享，央地事权与支出责任清晰。法治端：总结试点经验，适时将长护险写入医疗保障法或专门法规（与 S-001“拟入法”衔接）。

（6）收束

长护险不是“发钱险”，而是“买服务险”；不是医保的简单延伸，而是社会保障体系的独立支柱。它的成败，不只在费率高低，更在评估是否公平、服务是否可及、监管是否有效、制度是否可持续。

一句话收束：“第六险”补的不是医疗，而是失能后的生活；评估是入口，服务是载体，基金是底线，法治是长远。

6. 金句与术语

  1. “从‘一人失能、全家失衡’到‘制度分担、专业照护’，长护险改变的是照护的责任结构。”

二、案例速览

速览 1｜上海5家综合医院薪酬制度改革：让医生“靠技术吃饭”（管理学）

  • 事实：2026年4月17日，国家卫生健康委在上海召开“因地制宜推广三明医改经验”新闻发布会。上海市人民政府副秘书长章雄介绍，上海选择5家大型综合医院开展内部薪酬制度改革试点，优化医务人员薪酬结构，缩小临床科室间薪酬水平差距，合理确定各类岗位薪酬比例关系，构建“以岗定责、以岗定薪、责薪相适、考核兑现”的薪酬分配体系。配套改革包括：“十四五”期间政府卫生投入从2020年544.5亿元增加到2025年719亿元，年均增长5.7%；盘活事业编制1万余个，为中山医院、华山医院等增加编制1100个；常态化调整医疗服务价格659项次，新增免陪照护、脑机接口等价格项目；建立89个区域和专科医联体。
  • 核心考点：激励理论（公平理论、期望理论、双因素理论）、薪酬结构、绩效管理、公立医院公益性、三医协同。
  • 命题角度：结合材料，分析公立医院薪酬制度改革如何兼顾公益性与医务人员积极性。
  • 一句话结论：薪酬改革不是“普涨工资”，而是“结构—差距—考核—来源”的联动改革；让医生靠技术和服务获得体面收入，而不是靠开单提成。
  • 来源：澎湃新闻 2026-04-17；国家卫健委发布会（国新办转载）2026-04-17

速览 2｜中国医生职业倦怠61%：一个“组织问题”，不是“个人抗压问题”（组织行为学）

  • 事实：2025年11月5日，BMC Public Health 发表一项系统综述与元分析，纳入133项研究、193,866名中国医生。结果显示，中国医生职业倦怠的合并发生率为61%，重度职业倦怠率为12%；研究提示不同科室之间存在明显差异。从组织行为学看，职业倦怠通常与工作负荷、自主性、付出—回报失衡、组织支持不足等因素相关。（近三年案例）
  • 核心考点：职业倦怠（情绪耗竭、去人格化、低成就感）、工作压力、组织支持、心理契约、离职意愿、工作满意度。
  • 命题角度：结合材料，分析医生职业倦怠的成因，并从组织层面提出干预对策。
  • 一句话结论：倦怠不是“抗压能力差”，而是“负荷—自主—回报—支持”失衡的信号；干预要改组织，不能只做心理讲座。
  • 来源：BMC Public Health 2025;25:3787，DOI: 10.1186/s12889-025-25034-8

速览 3｜2024年度“国考”放榜：公立医院高质量发展的“指挥棒”（卫生事业管理学）

  • 事实：2026年4月9日，国家卫生健康委公布2024年度全国三级公立医院绩效监测（俗称“国考”）结果。本次监测覆盖综合、中医、专科三类医院，其中三级综合医院1658家、三级中医综合医院662家参加。监测围绕医疗质量、运营效率、持续发展、满意度评价四大维度、26项国家监测指标，以A++、A+、A等等级公布结果。此前，国家卫健委已印发《国家三级公立医院绩效监测操作手册（2025版）》，对监测指标和口径作出规范。
  • 核心考点：公立医院绩效考核、高质量发展、公益性、运营效率、患者满意度、功能定位（CMI、四级手术、下转）。
  • 命题角度：结合“国考”指标与结果，论述公立医院高质量发展的评价导向及其局限。
  • 一句话结论：“国考”用统一标尺把公益性、质量、效率、满意度量化，但要把“指挥棒”指向前1%的排名之外——功能定位、患者体验、基层协同和长期发展。
  • 来源：呼伦贝尔市卫生健康委 2026-04-13；国家卫健委《国家三级公立医院绩效监测操作手册（2025版）》2025-06-27

速览 4｜广东免陪照护“第二批”：一项政策试点如何从“试”走向“推”（公共政策导论）

  • 事实：2025年5月，国家卫生健康委、国家中医药局、国家疾控局印发《医院免陪照护服务试点工作方案》（国卫办医政发〔2025〕7号），2025年6月至2027年6月，在综合医改重点省份、人口老龄化程度较深的城市，选择老年住院患者占比较高、需求较大的三级医院开展试点；免陪照护服务由护士或医院聘用的医疗护理员提供，患者或家属知情同意、自愿选择。国家医保局在护理类医疗服务价格项目立项指南中单设“免陪照护服务”价格项目，实行政府指导价。广东2025年4月公布首批8个试点地区47家医疗机构（粤卫办医函〔2025〕16号）；2026年8月18日又公布第二批5家（粤卫办医函〔2026〕19号），包括广州医科大学附属番禺中心医院。
  • 核心考点：政策试点、政策扩散、政策执行、政策评估、政策工具（价格项目/服务供给）、街头官僚。
  • 命题角度：结合广东两批试点，分析免陪照护政策试点的逻辑、难点与推广条件。
  • 一句话结论：试点是“小范围试错—评估—扩散”；免陪照护要推广，关键在护理员供给、价格与支付、责任边界、患者选择权和监管标准。
  • 来源：广东省卫健委 2025-04-27；广东省卫健委 2026-08-24；中国政府网 2025-05-27

一、今日精析｜广东按病种付费经办规程：DRG/DIP 从“扩面”走向“精细化管理”（医疗保障学）

1. 案例材料（可直接作材料分析题题干）

2026年3月12日，广东省医疗保障局印发《广东省按病种付费医疗保障经办管理规程》，自2026年5月1日起施行，有效期5年。规程把 DRG（按疾病诊断相关分组付费）和 DIP（按病种分值付费）统一纳入“按病种付费”，覆盖协议管理、数据采集、预算管理、核心要素、特殊病例单议、结算清算、审核核查、配套机制等环节。

在预算端，年度按病种付费可分配资金总额增长率不得高于10%，可预留不超过10%的风险调节金用于合理超支分担；在结算端，月度结算可预留不超过5%的质量保证金，并要求压缩结算周期、推进即时结算；在例外端，住院时间长、费用高、使用新药新技术的复杂病例可申报“特殊病例单议”，例数原则上不超过 DRG 结算人次的5%或 DIP 结算人次的5‰；在监管端，要求对高套病种、分解住院、低标入院、推诿病人、转嫁住院费用等疑点开展核查，并将考核评价与年度清算挂钩。

这套规则承接国家医保局2025年印发的《医疗保障按病种付费管理暂行办法》和《按病种付费医疗保障经办管理规程（2025版）》，标志着按病种付费从“扩面”进入“精细化管理”阶段。

4. 命题角度

  • 名词解释：按病种付费（DRG/DIP）
  • 简答：简述按病种付费“预算—分组—结算—清算—监管”闭环的基本内容。
  • 论述：结合广东规程，论述 DRG/DIP 支付方式改革对医院行为、患者负担和医保基金的影响，并提出配套政策。
  • 材料分析：材料中的“总额预算增长率不高于10%”“特殊病例单议”“质量保证金”分别解决什么问题？这对医保精细化管理有何启示？

5. 答题框架（背这一页）

（1）内涵：从“为项目买单”到“为病种/健康结果买单” 按病种付费把医保基金从“按服务数量付费”转为“按病种打包付费”，医保部门从“被动报销”转向“战略购买”，医院从“多做项目多收入”转向“控成本、提效率、保质量”。

（2）机制：一个闭环 预算（区域总额、增长率上限、风险调节金）→ 分组（DRG 细分组 / DIP 病种目录）→ 分值或点值 → 月度结算（质量保证金、即时结算）→ 年度清算（结余留用、超支分担、二次分配）→ 考核监管（智能审核、特殊病例单议、协议管理）。

（3）影响：三方两面的“双刃剑”

  • 医院：倒逼成本核算、病案质量、临床路径、学科结构调整；风险是高套病种、分解住院、低标入院、推诿重症、抑制新技术。
  • 患者：控费可减轻负担，但若监管不到位，可能出现服务不足、推诿、自费转嫁。
  • 医保：提高基金使用效率、增强可持续性，但需防止“控费”压倒“提质”。

（4）配套：用“例外机制+质量考核”校准激励 特殊病例单议守住重症和新技术的可及性；质量保证金和考核评价防止“为控费而降质”；智能审核和协议管理守住基金安全；协商谈判和数据公开降低医院的不确定性；紧密型医共体总额付费则把“控费”升级为“健康管理”。

（5）收束 支付方式改革不是单纯“控费”，而是医保购买机制的重构；成败不只在分组技术，更在利益分配、质量考核和多部门协同。

一句话收束：总额预算管住“总盘子”，结余留用形成“内生动力”，特殊病例单议守住“例外公平”，智能监管守住“基金安全”。

6. 金句与术语

  1. “从按项目付费转向按病种付费，本质是把医保基金从‘为服务数量买单’转向‘为合理诊疗和健康结果买单’。”
  2. “DRG/DIP 不是万能钥匙，单病种付费可能带来高套、分解、推诿等逆向选择，必须用质量考核和例外机制校准。”
  3. “支付方式是医保、医疗、医药协同发展的‘总开关’。”
  4. “改革的难点不在技术分组，而在利益分配与行为激励。”
  5. “控费是手段，提质是目的，患者获益是底线。”

《医疗保障法（草案）》三审：医保治理从“政策推动”走向“法治保障”

2026年8月25日，十四届全国人大常委会第二十四次会议审议《中华人民共和国医疗保障法（草案）》三审稿。草案二审稿已于2026年4月提请十四届全国人大常委会第二十二次会议审议。2026年4月30日至5月29日公开征求意见期间，中国人大网收到343人次提出的1845条意见，代表工作信息化平台收到14位全国人大代表提出的39条意见，另收到来信10封。

三审稿拟作六方面修改：一是立法目的进一步体现健康优先发展战略；二是完善医疗保障体系有关规定；三是充实医疗保障基金管理有关规定；四是细化异地就医医药费用结算要求；五是增加长期护理保险相关规定；六是完善有关法律责任规定。

在基金管理方面，草案明确：国务院医疗保障行政部门在组织制定基本医疗保险基金支付范围、组织开展循证医学和经济性评价时，除征求有关部门意见外，还应当采取适当方式听取医疗机构、药品经营单位、相关企业、专家和参保人员的意见；建立和完善药品、医用耗材集中采购制度；实行多元复合式医疗保险支付方式；优化异地就医直接结算服务。

目前草案仍处于审议阶段，尚未颁布实施。

五、答题框架（背这一页）

（1）为什么立法：从“政策推动”到“法治保障” 医保改革已进入深水区，靠文件推动容易出现政策碎片化、地方执行差异、部门协调困难。把医保体系、基金、待遇、支付、监管等基本制度上升为法律，可以稳定预期、规范权力、保障参保人权利，为“三医协同”提供法治基础。

（2）立法过程：一次典型的政策合法化 起草 → 公开征求意见（343人次、1845条意见）→ 二审 → 三审 → 表决通过 → 公布施行。公开征求意见把医疗机构、医药企业、专家、参保人的多元利益纳入决策，提高立法的科学性与民主性；人大审议则完成合法性确认。

（3）三审亮点：六个“更”

  • 立法目的更鲜明：体现健康优先发展战略；
  • 体系更完整：完善医疗保障体系有关规定；
  • 基金更安全：充实基金管理规定，支付范围、循证医学和经济性评价要听取多方意见；
  • 结算更便捷：细化异地就医医药费用结算；
  • 制度更定型：增加长期护理保险；
  • 责任更严格：完善法律责任规定。

（4）难点：立法之后怎么落地 部门协同（医保、卫健、药监、财政）、央地事权与支出责任、待遇公平与基金可持续、长护险筹资与失能评估、法律与现行政策的衔接、监管能力与执法队伍。

（5）意义：医保治理现代化 对参保人：权利有法律保障；对医疗机构：规则更稳定、预期更明确；对医保部门：从行政推动转向依法治理；对医药企业：集采、支付、价格规则法治化；对国家：多层次医疗保障体系和健康中国战略的法治支撑。

一句话收束：医保法不是把现有政策简单“抄”进法律，而是把医保治理的基本关系、基本规则和基本责任固定下来，让改革“于法有据”。
